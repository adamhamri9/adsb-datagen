# Contributing to adsb-generator

## Process

1. **Select an issue** from the [issues page](https://github.com/adamhamri/adsb-datagen/issues).
2. **Fork the repository.**
3. **Create a branch** using the format `fix/description` or `feature/description`.
4. **Implement and test your changes.** Do not break existing functionality.
5. **Submit a Pull Request** with a clear description of the changes.

## Guidelines

- For **new features or significant changes**, contact **adamhamri9@proton.me** before starting work.
- **Minor fixes and documentation updates** may be submitted directly via PR.

Submissions will be reviewed against the project roadmap.

Thanks for the interest.
